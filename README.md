# Insightly CRM — интерактивная демка

Статический HTML-прототип CRM-панели, подготовленный из пользовательского архива `crm.zip`. Публичное демо: GitHub Pages.

## Запуск локально

```sh
node server.mjs
```

Откройте `http://127.0.0.1:4310`. Установка зависимостей не требуется.

## Возможности прототипа

- выбор и поиск контактов, сортировка и избранное;
- редактирование, блокировка и связь контактов с организациями;
- заметки с чекбоксами, проекты, сделки и просмотр файлов;
- экспорт контактов в CSV, календарь, настройки и экран блокировки;
- режимы презентации **App**, **Shot** и **3D** — переключатель внизу экрана или клавиши `1`, `2`, `3`;
- состояние демо сохраняется в `localStorage`; пункт **Settings → Reset demo data** сбрасывает изменения.

Данные контактов предназначены только для демонстрации. Загруженные в браузере файлы и внесённые изменения не отправляются на сервер.

## Структура

- `index.html` — интерфейс и SVG-иконки;
- `css/styles.css` — стили;
- `js/data.js` — демонстрационные контакты и связанные данные;
- `js/app.js` — отрисовка и взаимодействия;
- `assets/` — изображения аватаров, документов и логотипа.

Прототип создан как воссоздание макета Insightly CRM от RonDesignLab: https://dribbble.com/shots/23744603-Insightly-CRM-Contact-Information-Dashboard. Исходные референсные изображения из архива не включены в этот репозиторий.
